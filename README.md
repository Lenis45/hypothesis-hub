# Hypothesis Hub

Тёмное рабочее пространство для продуктовых гипотез: от быстрой идеи до измеримого эксперимента. Заменяет Google Sheets как источник истины, считает RICE, хранит HADI-контекст и даёт Telegram-ассистенту Amori read-only данные для анализа.

## Что умеет

- Создание гипотезы через короткий сценарий: идея → формулировка → RICE → план → проверка.
- RICE-приоритизация: охват × влияние × уверенность / усилия; шкалы хранят подпись и числовой вес.
- Реестр с поиском и фильтром по статусу, экспорт текущего реестра в CSV.
- Доска процесса с серверной проверкой допустимых переходов между статусами.
- Карточка HADI: гипотеза, список действий, способ измерения, ожидаемый положительный и отрицательный эффект, результаты эксперимента.
- Импорт `.xlsx`/CSV из исходного Google Sheets без тысяч пустых строк, `TBD`, `#REF!` и скрытого ICE-листа.
- Read-only API для Amori: в Telegram можно запросить анализ портфеля через `/hypotheses`.

## Стек

Next.js 16, React 19, TypeScript, Prisma 6, PostgreSQL 16, Auth.js, Tailwind CSS, Vitest и SheetJS.

## Быстрый запуск

### Требования

- Node.js 24+;
- Docker Desktop с Docker Compose.

### Локальная среда

```bash
cp .env.example .env
docker compose up -d
npm install
npx prisma generate
npx prisma migrate deploy
npm run prisma:seed
npm run dev
```

Приложение откроется на адресе из вывода Next.js; PostgreSQL опубликован на `localhost:5433`, чтобы не конфликтовать с локальной базой на стандартном порту `5432`.

Seed создаёт рабочее пространство «Команда продукта», одну цель, этапы воронки, администратора `admin@local.test` и несколько демо-гипотез. В production используйте сессию Auth.js и членство в рабочем пространстве; `DEMO_ADMIN_EMAIL` предназначен только для локальной разработки.

## Основной сценарий

1. Нажмите «Новая гипотеза».
2. Опишите идею и выберите цель/этап воронки.
3. Сформулируйте проверяемую HADI-гипотезу, действия и сигнал измерения.
4. Выберите RICE-параметры — балл и его интерпретация посчитаются сразу.
5. Задайте дату результата, критерий успеха и риск.
6. Созданная карточка попадает в реестр и на доску; статус меняется только разрешённой серверной операцией.

RICE — способ сравнить варианты, а не обещание эффекта. Карточка всегда хранит условия и данные, на которых основано решение.

## Проекты, цели и воронки

Откройте «Проекты» в боковом меню. Здесь можно:

- создать новый проект — он получает отдельный реестр, аналитику, воронку и стандартную RICE-шкалу, без переноса данных предыдущего проекта;
- переключить активный проект: весь интерфейс, экспорт и импорт работают только в его контексте;
- добавить измеримую цель с текущим и целевым значениями, периодом и метрикой;
- добавить этапы воронки в нужном порядке;
- посмотреть действующую RICE-методику и числовой вес каждого варианта оценки.

Новый проект намеренно начинается без целей и этапов: сначала задайте свой контекст в «Проектах», затем создавайте гипотезы через мастер.

## Импорт из Google Sheets

1. В Google Sheets выберите «Файл → Скачать → Microsoft Excel (.xlsx)».
2. Откройте в приложении раздел «Импорт» и выберите файл.
3. Проверьте предпросмотр и подтвердите импорт.

Поддерживаются листы «Идеи», «Идеи этапа воронки 1» и «Гипотезы+приоритеты». Импортируются только строки с непустой идеей. Пустые предзаполненные строки, `TBD`, ошибки формул и скрытый лист `ICE` игнорируются. Нераспознанные шкалы и неоднозначные поля фиксируются в журнале импорта, а не угадываются.

## Интеграция с Amori / Telegram

Amori получает только read-only снимок портфеля: цели, агрегаты, до 30 гипотез, RICE, сроки и последние результаты экспериментов. Он не меняет статусы и не создаёт записи из Telegram.

Для локальной разработки с Amori на той же машине достаточно запустить оба сервиса: маршрут `GET /api/amori/summary` доступен локально в development-режиме. В Telegram у Emilia используйте:

```text
/hypotheses
/hypotheses какие две гипотезы стоит сделать на этой неделе?
```

Для production укажите один и тот же длинный случайный секрет в двух местах:

```dotenv
# hypothesis-hub/.env
AMORI_INTEGRATION_TOKEN="..."

# ai-infra/agents/.env
HYPOTHESIS_HUB_API_URL="https://your-hypothesis-hub.example"
HYPOTHESIS_HUB_TOKEN="..."
```

Amori передаёт снимок в уже настроенную LLM и возвращает краткий ответ: вывод, обоснование цифрами, риски и 1–3 следующих шага. При ошибке сети, авторизации или отсутствии данных он сообщает об этом, а не выдумывает анализ.

## Роли

| Роль | Права |
| --- | --- |
| `ADMIN` | пространство, участники, шкалы, импорт и все действия с гипотезами |
| `EDITOR` | создание, редактирование, оценка и ведение экспериментов |
| `VIEWER` | просмотр и экспорт CSV |

Права проверяются в серверных actions/API, а не только скрытием кнопок в интерфейсе.

## Проверки

Тесты покрывают расчёт RICE, неполные оценки, нормализацию дубликатов, переходы статусов и очистку импорта от `TBD`/`#REF!`/ICE. Перед публикацией запускаются:

```bash
npm test
npx tsc --noEmit
npm run build
```

## Безопасность данных

- `.env` и токены не попадают в Git.
- В production снимок для Amori защищён заголовком `x-amori-token`.
- Интеграция read-only: Telegram-агент не выполняет изменения в рабочем пространстве.
- Для публичного хостинга включите HTTPS, production-Auth.js и уникальный `AMORI_INTEGRATION_TOKEN`.
